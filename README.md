A pie chart widget for Grist that instantly visualizes all selected numerical values from the row you're viewing—ideal for budgets, recipes, or any table where you have lots of columns with numbers (costs, percentages, breakdowns) on the same row. See the proportions at a glance without rearranging your table.

**What does it do?**  
- Shows a clear pie chart of the current record.
- Each metric you select becomes a slice.
- Legend, colors, and totals make comparisons fast and obvious.

**Who is it for?**  
- Anyone analyzing one row at a time (e.g., budgets, recipes, cost centers, breakdowns).
- Users who want a visual summary instead of scanning numbers.

**What do you get?**  
- A customizable pie chart, always linked to the active row in your Grist document.
